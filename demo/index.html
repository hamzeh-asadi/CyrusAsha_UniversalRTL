حتماً! برای راست‌چین‌کردن لیست پیام‌ها کل صفحه را آینه نکن؛ فقط ظرف هر پیام را جهت‌دهی کن. ساده‌ترین راه استفاده از ویژگی استاندارد dir است:

  • روی هر پیام مقدار dir="auto" بده تا مرورگر خودش جهت را تشخیص دهد.
  • برای کنترل دقیق‌تر از همان موتور CyrusAsha_UniversalRTL-1.0.0 استفاده کن.
const el = document.querySelector(".message");
el.setAttribute("dir", detectDirection(el.textContent));
