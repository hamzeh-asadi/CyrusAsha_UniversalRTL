افزونه‌ی مرورگر CyrusAsha_UniversalRTL-1.0.0 برای Chrome/Edge و Firefox؛ با روشن/خاموش کلی و تنظیم جداگانه‌ی هر سایت.
دانلود بسته‌ی Chrome (.crx) دانلود ZIP فروشگاه Chrome / Edge دانلود افزونه‌ی Firefox
CRX بسته‌بندی‌شده است؛ قوانین Chrome ممکن است نصب محلی را مسدود کند. برای انتشار عادی، ZIP را به Chrome Web Store بده. ZIP برای Edge Add-ons است. XPI محلی Firefox موقت است و نصب دائمی به امضای Mozilla نیاز دارد.
برای چت مایکروسافت در Edge از Microsoft Copilot استفاده کن؛ www.bing.com صفحه‌ی جست‌وجوست، نه چت.
